Seminar Presentation
====================

This directory contains a seminar presentation about the paper “Extracting Syntactic Patterns from Databases”, available [here](https://ieeexplore.ieee.org/abstract/document/8509235). The presentation slides can be found at `main.pdf`, and have been generated from the LaTeX file at `main.tex`.

> Andrew Ilyas et al. (2018). “Extracting syntactical patterns from databases”. In: 2018 IEEE 34th International Conference on Data Engineering (ICDE). IEEE, pp. 41–52
