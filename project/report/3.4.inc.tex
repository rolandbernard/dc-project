
\subsection{Inclusion Dependency Discovery} \label{inc}

The BINDER algorithm implementation in Metanome has been used for inclusion dependency discovery in this project. The algorithm used by this implementation is following the divide and conquer-based approach presented in \cite{papenbrock2015divide}. The analysis has been run once over all five tables used in this project. Multi-column dependency discovery has initially been enabled, however, because it generates a very large number of 1024 different inclusion dependencies it became infeasible to analyze them. Therefore, the final evaluation uses the results of single-column inclusion dependency detection, only mentioning some particularly relevant multi-column inclusion dependencies. This analysis can be used to find candidate for foreign keys between the different tables in the dataset which can be applied to the relational schema designed in \cref{relational}.
