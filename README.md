Data Curation Projects
======================

This repository contains resources related to a university course on Data Profiling and Data Curation. Concretely it includes two things:
* `presentation_dp/` contains the slides for an optional presentation of a data profiling related paper. More information in [`README.md`](presentation_dp/README.md).
* `project/` contains the code and documentation for the course project. More information to be found in that folders [`README.md`](project/README.md).
